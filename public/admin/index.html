      Tracking chuyển đổi Facebook (Pixel + CAPI)

      Tích hợp song song Meta Pixel (trình duyệt) & Conversions API (máy chủ) với chống trùng lặp event_id.

      Cấu hình Meta Pixel & Conversions API

      Dán nguyên đoạn mã từ Meta Events Manager — hệ thống tự tách Pixel ID, chèn ngay trước thẻ </head> và đồng bộ với CAPI.

      
          
      

          
      
            
      Hướng dẫn gắn Tracking chuẩn
      
            
        
              
      • Deduplication tự động: Mỗi lần khách gửi form, hệ thống tạo một event_id duy nhất gửi đồng thời qua fbq('track','Lead') và Server CAPI để Meta tự động gộp, không đếm trùng.
        • 
              
      • Mã hóa SHA-256: Số điện thoại (chuẩn E.164), tên và khu vực được băm SHA-256 ở backend trước khi gửi lên Graph API v27.0, tăng điểm Event Match Quality (EMQ).
        • 
              
      • Ghi nhận UTM & FBCLID: Tự động bắt fbclid, _fbp, _fbc, utm_source, utm_campaign ngay khi khách bấm quảng cáo.
        • 
              
      • Gửi sự kiện chốt đơn: Ở tab Dataform & Leads, bạn có thể bấm nút CAPI trên từng khách hàng để gửi sự kiện Schedule (Đã hẹn khảo sát) hoặc Purchase (Đã chốt hợp đồng) ngược về Meta để tối ưu tệp quảng cáo!

          Đổi mật khẩu quản trị
          
            
          
              
              
            
          
            
          
              
              
            
          
            
          
          

          
          
            
          Các lớp bảo mật đang kích hoạt
          
            
            
              
          • ✅ HTTP Security Headers (Helmet + CSP): Chống XSS, Clickjacking, MIME sniffing.
            • 
              
          • ✅ Chống Brute-Force & Spam: Rate-limiting trên API form & đăng nhập + khóa tài khoản tạm thời sau 5 lần sai mật khẩu + Honeypot ẩn trên form.
            • 
              
          • ✅ Phiên đăng nhập an toàn: JWT lưu trong cookie HttpOnly + SameSite=Strict + bảo vệ CSRF bằng X-CSRF-Token.
            • 
              
          • ✅ Bảo mật Database: 100% truy vấn tham số hóa (Prepared Statements), ràng buộc UNIQUE trên số điện thoại chuẩn hóa E.164, SQLite WAL mode.
            • 
              
          • ✅ Bảo mật Upload: Xác thực Magic Bytes nhị phân (chỉ cho phép JPG/PNG/WebP/GIF, chặn SVG/JS giả mạo).
